# LWhisper

Десктопное приложение для голосового ввода текста с использованием Whisper AI.

## Возможности

- 🎤 **Голосовой ввод**: Записывайте речь и автоматически преобразуйте её в текст
- 🌍 **Мультиязычность**: Автоматическое определение русского и английского языков
- 🎯 **Плавающий виджет**: Удобный интерфейс, всегда под рукой
- ⌨️ **Горячие клавиши**: Быстрый доступ через глобальные хоткеи
- 📋 **Предпросмотр**: Редактирование текста перед вставкой
- 🔒 **Оффлайн**: Работает полностью локально без интернета

## Требования

- Windows 10/11
- .NET 8.0 Runtime
- Микрофон
- Модель Whisper (скачивается отдельно)

## Установка

### 1. Скачать модель Whisper

Скачайте модель `ggml-small.bin` (~500 MB) с HuggingFace:
https://huggingface.co/ggerganov/whisper.cpp/tree/main

Поместите файл в папку `Models/` проекта.

### 2. Запуск

```bash
dotnet run --project LWhisper.UI.WPF
```

Или откройте `LWhisperer.sln` в Visual Studio и нажмите F5.

## Использование

### Режимы записи

1. **Toggle** (по умолчанию): Клик для начала записи, повторный клик для остановки
2. **Push-to-Talk**: Зажмите кнопку мыши для записи
3. **Hotkey**: Используйте глобальную горячую клавишу (Ctrl+Shift+Space)

### Настройки

Кликните правой кнопкой на иконке в трее → Настройки

- Выбор устройства записи
- Режим записи
- Задержка автовставки
- Горячие клавиши

### Интерфейс

- **Синий круг**: Готов к записи
- **Красный пульсирующий**: Идет запись
- **Желтый с анимацией**: Обработка речи

## Архитектура

Проект разделен на три модуля:

```
LWhisper.Core          # Интерфейсы и модели (кросс-платформенные)
LWhisper.SpeechEngine  # Реализация Whisper
LWhisper.UI.WPF        # Windows UI и специфичные сервисы
```

Эта архитектура позволяет легко портировать на Linux/Home Assistant.

## Разработка

### Структура решения

- `/LWhisper.Core` - Базовые интерфейсы без зависимостей от платформы
- `/LWhisper.SpeechEngine` - Интеграция с Whisper.net
- `/LWhisper.UI.WPF` - WPF приложение и Windows-специфичный код
- `/Models` - Папка для моделей Whisper

### Зависимости

- **Whisper.net**: Распознавание речи
- **NAudio**: Запись звука
- **Hardcodet.NotifyIcon.Wpf**: Системный трей
- **Serilog**: Логирование

### Сборка

```bash
dotnet build
```

### Логи

Логи сохраняются в `%APPDATA%\LWhisper\logs\`

## Настройки

Файл настроек: `%APPDATA%\LWhisper\settings.json`

```json
{
  "RecordingMode": "Toggle",
  "HotkeyBinding": "Ctrl+Shift+Space",
  "AutoInsertDelaySeconds": 2,
  "WidgetPositionX": 100,
  "WidgetPositionY": 100,
  "RecognitionLanguage": "auto",
  "WhisperModelSize": "small"
}
```
