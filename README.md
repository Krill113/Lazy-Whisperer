# LWhisper

Десктопное приложение для **офлайн голосового ввода текста** в Windows на базе Whisper AI. Захватывает звук с микрофона, распознаёт речь локально через [Whisper.net](https://github.com/sandrohanea/whisper.net) и вставляет результат в активное окно.

> **«Офлайн»** здесь про распознавание: модели Whisper работают локально, без облачных платных ASR-сервисов. Сеть используется только для скачивания моделей и проверки обновлений.

## Возможности

- 🎤 Голосовой ввод в любое активное окно Windows
- 🌍 Авто-определение русского и английского
- 🎯 Плавающий виджет — всегда под рукой
- ⌨️ Глобальные горячие клавиши (по умолчанию `Ctrl+Shift+Space`)
- 📋 Предпросмотр и правка текста перед вставкой
- 🌊 Потоковый режим с VAD (распознавание по сегментам)
- 🔒 Распознавание полностью локальное

## Установка

### Готовый релиз (рекомендуется)

1. Скачайте `LWhisper-win-x64-vX.Y.Z.zip` со страницы [Releases](https://github.com/Krill113/Lazy-Whisperer/releases).
2. Распакуйте в папку **с правом записи** (профиль/Документы, **не** `Program Files`).
3. Запустите `LWhisper.UI.WPF.exe`.

> ⚠️ Приложение пока не подписано — при первом запуске SmartScreen может предупредить: «Подробнее» → «Выполнить в любом случае».
>
> Распространяйте/запускайте **всю папку** (`exe` + `runtimes\` + `WebRtcVad.dll`), не только exe.

### Модель Whisper

Скачивается по требованию из окна Настроек в `%APPDATA%\LWhisper\Models\`. Модели Whisper — лицензия MIT (OpenAI), скачиваются отдельно от приложения.

## Использование

- **Режимы записи:** Toggle (клик старт/стоп), Push-to-Talk, Hotkey.
- **Настройки:** правый клик по иконке в трее → Настройки (устройство, режим, задержка автовставки, хоткеи, потоковый режим).
- **Состояния виджета:** синий — готов, красный пульс — запись, жёлтый — обработка.

## Требования

- Windows 10/11, микрофон
- Для сборки из исходников — .NET 8 SDK

## Сборка из исходников

```bash
dotnet build                              # обычная сборка
dotnet run --project LWhisper.UI.WPF      # запуск
build-release.bat Release                 # релизный self-contained single-file (win-x64)
```

## Архитектура

Три слоя — разделение намеренное, как задел под будущие фронтенды (Linux / Home Assistant):

```
LWhisper.Core          # Интерфейсы и модели (netstandard2.1, без внешних зависимостей)
LWhisper.SpeechEngine  # Обёртка Whisper.net (net8.0)
LWhisper.UI.WPF        # Windows UI и платформенные сервисы (net8.0-windows)
```

## Обновления

Приложение проверяет новые версии на GitHub при запуске (отключаемо в Настройках); обновление скачивается и устанавливается по запросу. *(в разработке)*
